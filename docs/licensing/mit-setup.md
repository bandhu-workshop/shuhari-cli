# MIT licensing setup

This project is licensed under the MIT License.

## Why MIT

MIT was chosen for its simplicity and permissiveness: it places almost no
restrictions on reuse, doesn't require a NOTICE-style attribution file (that's
an Apache-2.0-specific mechanism), and is well understood by anyone who might
depend on this code.

## Where it lives

- [`LICENSE`](../../LICENSE) — the full MIT license text, copyright
  Dinabandhu Behera.
- [`CITATION.cff`](../../CITATION.cff) — machine-readable citation metadata,
  so the project can be cited properly if referenced elsewhere.

## SPDX header convention

Every source file starts with:

```
# SPDX-FileCopyrightText: 2026 Dinabandhu Behera
# SPDX-License-Identifier: MIT
```

Add this header to new Python files, workflow files, and other source files
that support comments. Skip it for files where a leading comment would break
the format (e.g. some config/data files).
